### General Reflection

The **Workforce Bootcamp - First Cloud AI Journey** program helped me approach AWS through a clearer learning path, from basic cloud concepts to applying AWS knowledge in a real project. Through the **SmartHospital P2TB** project, I learned that a complete system requires not only UI, but also backend APIs, authentication, data storage, security, monitoring, and deployment workflow.

### What I Learned

* Better understood AWS services such as Cognito, Lambda, API Gateway, DynamoDB, S3, CloudFront, and CloudWatch.
* Learned how to connect cloud concepts with a real project that has multiple user roles.
* Practiced Flutter mobile development, API calls, JSON handling, and UI debugging.
* Understood teamwork better when different members work on backend, web, mobile, and infrastructure.
* Realized the importance of documentation, worklogs, and evidence during an internship.

### Most Valuable Experience

The most valuable experience was working on a project with a practical context. The hospital project helped me understand why role-based login is needed, why medical records must be synchronized, why payment status must be clear, and why the mobile app must follow backend logic instead of remaining a static UI demo.

### Challenges

* I initially faced several issues while setting up Flutter, running the emulator, and configuring Android Studio.
* At some points, I was not fully clear about the difference between demo mobile code and the official project branch.
* Report requirements changed several times, so I had to update the worklog, event section, and student information to match the template.
* Synchronizing mobile with backend required careful agreement on API names, field names, and business statuses.

### Suggestions

* Provide a clear report checklist from the beginning, especially the number of worklog weeks, required sections, and evidence requirements.
* Provide a more complete sample project/report for students to compare against.
* For group projects, finalize Git branches, merge rules, and member scopes early to reduce conflicts.
* Add a short session on collecting evidence, writing worklogs, and presenting event participation.

### Conclusion

I believe the program helped me gain practical knowledge about AWS, project workflow, and team collaboration. After this process, I feel more confident working with Flutter mobile, backend APIs, and technical reports using the required template.
