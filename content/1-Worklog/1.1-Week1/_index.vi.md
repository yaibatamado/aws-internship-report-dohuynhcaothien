### Mục tiêu tuần 1

* Làm quen với chương trình thực tập và định hướng học AWS.
* Tự học các khái niệm nền tảng về cloud computing từ AWS Study Group.
* Hiểu vai trò của AWS trong một hệ thống web/mobile thực tế.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| Tìm hiểu cloud | Học các khái niệm cơ bản như cloud computing, region, availability zone, scalability, high availability và pay-as-you-go. |
| Làm quen AWS | Xem nội dung nhập môn AWS Study Group để hiểu các nhóm dịch vụ chính: compute, storage, database, networking và security. |
| Ghi chú học tập | Ghi lại các thuật ngữ quan trọng và liên hệ với project bệnh viện dự kiến triển khai trên AWS. |
| Định hướng project | Xác định project cần có frontend, backend API, xác thực, lưu trữ dữ liệu và giám sát vận hành. |

### Kết quả đạt được

* Nắm được nền tảng cloud và cách AWS hỗ trợ triển khai ứng dụng.
* Hiểu các nhóm dịch vụ AWS chính sẽ xuất hiện trong project.
* Có định hướng ban đầu cho kiến trúc hệ thống bệnh viện trên AWS.
