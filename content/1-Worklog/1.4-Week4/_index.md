### Week 4 Objectives

* Self-study AWS storage and static hosting.
* Understand how S3 and CloudFront serve frontend applications.
* Relate storage services to medical documents and hospital web deployment.

### Completed Work

| Item | Description |
| --- | --- |
| S3 | Studied buckets, objects, versioning, public access block, and static website hosting. |
| CloudFront | Learned CDN, caching, invalidation, and static content distribution concepts. |
| Medical documents | Noted how S3 can store records, images, lab documents, and uploaded files. |
| Project mapping | Identified that the web frontend can be built as static assets, uploaded to S3, and distributed via CloudFront. |

### Outcomes

* Understood file storage and content distribution with S3/CloudFront.
* Learned the importance of not exposing sensitive medical data publicly.
* Prepared the foundation for document storage and frontend deployment.
