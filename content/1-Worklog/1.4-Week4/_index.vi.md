### Mục tiêu tuần 4

* Tự học storage và static hosting trên AWS.
* Hiểu cách S3 và CloudFront phục vụ frontend.
* Liên hệ với nhu cầu lưu tài liệu y tế và triển khai web bệnh viện.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| S3 | Tìm hiểu bucket, object, versioning, public access block và static website hosting. |
| CloudFront | Học vai trò CDN, cache, invalidation và phân phối nội dung tĩnh. |
| Tài liệu y tế | Ghi nhận cách S3 có thể lưu file hồ sơ, ảnh, tài liệu xét nghiệm hoặc file tải lên. |
| Liên hệ project | Xác định web frontend có thể build static, upload lên S3 và phân phối qua CloudFront. |

### Kết quả đạt được

* Hiểu cách lưu trữ file và phân phối nội dung với S3/CloudFront.
* Nắm được nguyên tắc không mở public dữ liệu y tế nhạy cảm.
* Có cơ sở cho phần lưu trữ tài liệu và triển khai frontend của project.
