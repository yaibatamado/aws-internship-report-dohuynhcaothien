### Mục tiêu tuần 7

* Tự học monitoring và vận hành trên AWS.
* Hiểu CloudWatch Logs, metrics, alarm và cách debug hệ thống.
* Chuẩn bị kiến thức kiểm tra lỗi khi backend/mobile gặp sự cố.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| CloudWatch Logs | Tìm hiểu cách xem log Lambda và API để xác định lỗi. |
| Metrics | Học các chỉ số cơ bản như invocation, error, duration, 4xx/5xx và latency. |
| Alarm | Tìm hiểu cách cảnh báo khi hệ thống lỗi hoặc có độ trễ cao. |
| Liên hệ project | Ghi nhận cách kiểm tra lỗi login, API 500, token sai, CORS hoặc dữ liệu rỗng. |

### Kết quả đạt được

* Nắm được cách theo dõi và debug hệ thống AWS.
* Hiểu tầm quan trọng của log/metric khi ứng dụng mobile gọi backend.
* Chuẩn bị kỹ năng vận hành cơ bản cho giai đoạn project.
