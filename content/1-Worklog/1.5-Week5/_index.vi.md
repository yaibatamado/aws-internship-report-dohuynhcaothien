### Mục tiêu tuần 5

* Tự học các dịch vụ database trên AWS.
* Hiểu khác biệt giữa database quan hệ và NoSQL.
* Chuẩn bị kiến thức DynamoDB cho project bệnh viện.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| Database AWS | Tìm hiểu RDS, DynamoDB và các trường hợp sử dụng phổ biến. |
| DynamoDB | Học khái niệm table, item, partition key, sort key và truy vấn dữ liệu theo access pattern. |
| Thiết kế dữ liệu | Ghi chú cách thiết kế dữ liệu cho bệnh nhân, bác sĩ, lịch hẹn, hồ sơ bệnh án và hóa đơn. |
| Liên hệ project | Nhận diện nhu cầu lưu dữ liệu theo vai trò và theo mã hồ sơ bệnh án. |

### Kết quả đạt được

* Nắm được lý do chọn DynamoDB cho hệ thống serverless.
* Hiểu cơ bản cách thiết kế khóa dữ liệu theo nhu cầu truy vấn.
* Chuẩn bị kiến thức để đọc và phối hợp với backend trong project SmartHospital.
