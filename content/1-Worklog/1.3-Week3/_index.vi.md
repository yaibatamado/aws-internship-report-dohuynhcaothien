### Mục tiêu tuần 3

* Tự học các dịch vụ compute và mô hình chạy backend trên AWS.
* Hiểu sự khác nhau giữa EC2, container và serverless.
* Xác định hướng dùng Lambda/API Gateway cho backend bệnh viện.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| Compute | Tìm hiểu EC2, Lambda và khái niệm serverless compute. |
| API backend | Học cách API Gateway kết nối request từ frontend/mobile đến Lambda. |
| So sánh triển khai | Ghi chú ưu/nhược điểm giữa server truyền thống và serverless. |
| Liên hệ project | Xác định backend bệnh viện phù hợp với API Gateway + Lambda để giảm vận hành server. |

### Kết quả đạt được

* Hiểu cơ bản cách AWS chạy logic backend.
* Nắm được vai trò của API Gateway và Lambda trong kiến trúc serverless.
* Có định hướng backend phù hợp với project SmartHospital P2TB.
