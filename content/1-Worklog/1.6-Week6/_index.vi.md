### Mục tiêu tuần 6

* Tự học networking cơ bản trên AWS.
* Hiểu VPC, subnet, route table, security group và cách dịch vụ giao tiếp.
* Liên hệ networking với API, frontend và mobile.

### Công việc đã triển khai

| Hạng mục | Nội dung |
| --- | --- |
| VPC | Tìm hiểu VPC, public subnet, private subnet, route table và internet gateway. |
| Security group | Học cách kiểm soát inbound/outbound traffic. |
| API access | Ghi chú cách frontend/mobile gọi API public thông qua API Gateway/CloudFront. |
| Liên hệ project | Xác định các điểm cần chú ý khi mobile gọi backend: base URL, CORS, token và network error. |

### Kết quả đạt được

* Hiểu các khái niệm networking cơ bản trên AWS.
* Nắm được cách ứng dụng bên ngoài truy cập backend AWS an toàn.
* Có cơ sở xử lý lỗi kết nối khi phát triển mobile.
